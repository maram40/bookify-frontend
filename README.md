# Team Manager Application

A dynamic and interactive Team Manager Dashboard built with Angular.

##  Features
- **Display Team Members:** View members with details (Name, Age, Department, Availability Status).
- **Add New Members:** Simple form to add new members dynamically to the team.
- **Filter by Department:** Filter members by Development, Marketing, Design, or All.
- **Switch Views:** Toggle between **Card View** and **List View**.
- **Toggle Status:** Update member availability status (Available / Unavailable) in real-time with visual indicators.

## Angular Concepts Used
- **Modern Control Flow:** `@if`, `@for`, and `@switch`.
- **Two-Way Data Binding:** `[(ngModel)]` for form inputs.
- **Event Binding:** `(click)` for actions and status toggles.
- **Property & Style Binding:** Dynamic status styling for cards.
